# HUB Website

Sito ufficiale **HUB** - Fondocasa Hub Napoli.
Tre servizi integrati: Immobiliare · Creditizio · Assicurativo.

## Tecnologie
- React 18
- Vite
- Single Page Application con routing interno

## Sviluppo locale
```bash
npm install
npm run dev
```

## Build per produzione
```bash
npm run build
```

## Deploy
Il sito è configurato per il deploy automatico su Vercel.
Ogni push su questa repository genera un nuovo deploy.
