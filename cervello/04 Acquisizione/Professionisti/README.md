# Censimento professionisti

Per zona: notai, avvocati, amministratori di condominio, commercialisti, tecnici.
1. File grezzo in `_fonti/professionisti/<zona>.csv` (Google Maps, ordini professionali, elenchi).
2. `professionisti _fonti/professionisti/<zona>.csv` → CSV pulito e senza doppioni pronto per Vendilo.
3. Gli amministratori e i notai più importanti hanno una nota qui (modello `_modelli/Professionista.md`)
   con lo storico del rapporto.
