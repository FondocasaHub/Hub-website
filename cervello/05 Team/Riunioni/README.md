# Riunioni

1. Registra la riunione (telefono o Meet) e carica il file su Drive, cartella `Riunioni`.
2. Metti la trascrizione in `_fonti/riunioni/AAAA-MM-GG team.txt` (Meet la genera, oppure si trascrive dal Mac).
3. Comando `riunione _fonti/riunioni/AAAA-MM-GG team.txt`.

Il verbale ha: decisioni (che finiscono anche in `08 Decisioni/`), compiti con **una** persona e **una** data,
punti rimasti aperti. I compiti appaiono nel [[00 Cruscotto]] finché non vengono spuntati.
